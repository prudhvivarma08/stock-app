# Stock Data Desktop App

A cross-platform desktop application built with Electron and Node.js to view live stock data using Paytm Money Open APIs. The app displays interactive charts with selectable time ranges (Daily, Weekly, Monthly, Yearly, 5-Year, All Time) and key stock metrics (Open, High, Low, Close, Volume).

## Prerequisites
- Node.js (v16 or higher)
- Paytm Money API Key and Secret (register at https://developer.paytmmoney.com/)
- Git
